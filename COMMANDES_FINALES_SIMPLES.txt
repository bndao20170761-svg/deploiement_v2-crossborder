⚠️  NOTE IMPORTANTE SUR LE PORT 8080:
───────────────────────────────────────────────────────────────

Le port 8080 est en HTTP (pas HTTPS) parce que:
  → gateway-pvvih utilise déjà ce port
  → nginx-https ne peut pas l'utiliser (conflit)
  → Pour avoir SSL sur l'API, il faudrait:
    - Utiliser le port 8443 à la place
    - Ou router via /api/ sur le port 443
    - Et rebuild tous les frontends

Pour l'instant, HTTP sur 8080 est suffisant si:
  ✅ Votre réseau est interne/privé
  ✅ Vous testez en développement
  ✅ Vous avez un firewall entre internet et votre VM

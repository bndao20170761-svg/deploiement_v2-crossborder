==========================================================
COMMANDES À EXÉCUTER SUR LE SERVEUR GCP
==========================================================

Connectez-vous au serveur:
  ssh ec2-user@100.48.20.109

Puis exécutez ces commandes:

----------------------------------------------------------
OPTION 1: Script automatique (RECOMMANDÉ)
----------------------------------------------------------

cd ~/deploiement_v2-crossborder
chmod +x CORRECTION_FINALE_USER_PATH.sh
./CORRECTION_FINALE_USER_PATH.sh

Ce script va:
  1. Ajouter le port 3003 SSL dans nginx-https.conf
  2. Modifier le Dockerfile avec PUBLIC_URL=/user
  3. Corriger le proxy_pass pour /user/
  4. Rebuilder a-user-front
  5. Redémarrer les services
  6. Tester les URLs

----------------------------------------------------------
OPTION 2: Commandes manuelles
----------------------------------------------------------

# 1. Ajouter port 3003 SSL à nginx-https.conf
cd ~/deploiement_v2-crossborder

cat >> nginx-https.conf << 'EOF'

# Serveur séparé pour a-user-front sur port 3003
server {
    listen 3003 ssl;
    server_name _;
    ssl_certificate /etc/nginx/ssl/nginx-selfsigned.crt;
    ssl_certificate_key /etc/nginx/ssl/nginx-selfsigned.key;
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers HIGH:!aNULL:!MD5;
    ssl_prefer_server_ciphers on;

    location / {
        proxy_pass http://a-user-front:80;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
EOF

# 2. Ajouter PUBLIC_URL au Dockerfile
nano a_user_front/Dockerfile
# Ajouter après "ENV REACT_APP_FRONTEND2_URL=$REACT_APP_FRONTEND2_URL" :
#   ENV PUBLIC_URL=/user

# 3. Corriger location /user/ (enlever trailing slash du proxy_pass)
sed -i 's|proxy_pass http://a-user-front:80/;|proxy_pass http://a-user-front:80;|g' nginx-https.conf

# 4. Rebuilder et redémarrer
docker compose build --no-cache a-user-front
docker compose stop a-user-front nginx-https
docker compose rm -f a-user-front nginx-https
docker compose up -d a-user-front nginx-https

# 5. Attendre 30 secondes
sleep 30

# 6. Tester
curl -kI https://localhost:3003/
curl -kI https://localhost/user/

----------------------------------------------------------
DIAGNOSTIC SI ÇA NE MARCHE PAS
----------------------------------------------------------

# Vérifier que PUBLIC_URL a bien été appliqué
docker exec a-user-front cat /usr/share/nginx/html/index.html | grep static

# Devrait afficher:
#   <script src="/user/static/js/main.xxx.js"></script>
#   <link href="/user/static/css/main.xxx.css" rel="stylesheet">

# Si ça affiche "/static/..." au lieu de "/user/static/...",
# alors PUBLIC_URL n'a pas été pris en compte → il faut rebuilder

# Vérifier les ports ouverts
docker exec nginx-https nginx -T | grep "listen.*ssl"

# Devrait afficher:
#   listen 443 ssl;
#   listen 3001 ssl;
#   listen 3002 ssl;
#   listen 3003 ssl;

# Vérifier les logs nginx
docker logs nginx-https --tail 50

# Vérifier l'état des containers
docker ps | grep -E "(nginx-https|a-user-front)"

UTILISEZ LE PORT DIRECT QUI FONCTIONNE:

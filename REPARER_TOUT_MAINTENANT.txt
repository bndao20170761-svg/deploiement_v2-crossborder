=========================================
COMMANDES À EXÉCUTER SUR LE SERVEUR GCP
=========================================

Copiez-collez ces commandes UNE PAR UNE sur le serveur :

# 1. Aller dans le dossier du projet
cd ~/deploiement_v2-crossborder

# 2. Arrêter nginx-https
docker compose stop nginx-https

# 3. Supprimer le conteneur nginx-https
docker compose rm -f nginx-https

# 4. Redémarrer nginx-https avec la nouvelle config
docker compose up -d nginx-https

# 5. Attendre 5 secondes
sleep 5

# 6. Vérifier l'état
docker ps | grep nginx-https

# 7. Vérifier les logs
docker logs nginx-https --tail 30

# 8. Test rapide depuis le serveur
curl -k -I https://localhost:3001 | head -5
curl -k -I https://localhost:3002 | head -5
curl -k -I https://localhost:3003 | head -5

PROBLÈME IDENTIFIÉ ET RÉSOLU
===========================================

❌ PROBLÈME :
   - POST https://100.48.20.109/api/user-auth/login → 403/404
   - Nginx routait /api/ vers a-reference-front au lieu du gateway

❌ CAUSE :
   - Ordre incorrect des location dans nginx-https.conf
   - location / était AVANT location /api/
   - Nginx matchait "/" pour toutes les requêtes /api/...

✅ SOLUTION :
   - Mis location /api/ AVANT location /
   - Routes spécifiques doivent être avant routes génériques

ARCHITECTURE FINALE
===========================================

Utilisateur (navigateur)
    ↓ HTTPS (port 443)
nginx-https (certificat SSL)
    ├─→ /api/* → gateway-pvvih:8080 (HTTP interne)
    │              ↓
    │         Microservices (gestion-user, etc.)
    │
    └─→ /* → a-reference-front:80 (HTTP interne)

- Port 443 : HTTPS (nginx-https)
- Port 3001 : HTTPS (a-user-front direct)
- Port 3002 : HTTPS (gestion-forum-front direct)
- Ports 8080, 9089-9092 : HTTP interne (microservices)

Communication externe = HTTPS uniquement
Communication interne Docker = HTTP (sécurisé par réseau privé)
